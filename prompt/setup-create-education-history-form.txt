#Goals/Tujuan-utama
Buatkan aplikasi android dengan fitur sebagai berikut:
- Splash Screen sederhana yang muncul ketika aplikasi pertama kali dibuka (sudah ada dan sudah diimplementasikan)
- Login dan logout baik tampilan/interface maupun logic system menggunakan SharedPreferences (Sudah diimplementasikan)
- Dashboard pengguna (akan dijelaskan detailnya di bawah)
- Ada menu untuk input/menambah kegiatan harian seperti olahraga, belajar, bekerja atau belanja. Berikut adalah spesifikasi untuk apa saja yang perlu diinput:
  - Jenis kegiatan (dropdown dengan option yang sudah disebutkan tadi (olahraga, belajar, bekerja atau belanja))
  - Tanggal
  - Lokasi kegiatan
  - Catatan
- Setelah data diinputkan, user akan diarahkan ke halaman Data kegiatan
- Data kegiatan ini berisi daftar kegiatan yang sudah diinput oleh user. Ditampilkan dengan RecyclerView dan CardView.
- Setiap kegiatan dapat dihapus ataupun diedit dengan cara mengklik tombol yang ada di setiap data kegiatan di tampilan data kegiatan. Berikut adalah detail tambahannya:
 - Tampilkan alert konfirmasi saat user ingin menghapus salah satu data kegiatan.
 - Lempar ke halaman baru yaitu "Edit Kegiatan" saat user mengklik tombol edit salah satu data kegiatan.
- Dashboard pengguna berisi:
 - Card untuk menampilkan total kegiatan pada hari ini
 - Tombol untuk ke halaman input data kegiatan baru
