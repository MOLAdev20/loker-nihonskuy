== English Ver


Create Document Plan in plan/add-tag-in-vacancy.md

Objective:
Implement a tagging system for job vacancies to allow strategic classification (e.g., "Urgently Needed") and display them on the landing page.

Technical Requirements:

Database: Create a migration to add a nullable tags column (STRING) to the vacancies table.

Admin Implementation:

Add a "Special Tag" checkbox in the Create/Update vacancy forms.

Initially, provide one option: "Dibutuhkan Segera" (Value: urgent).

Store the tags as a delimited string (e.g., urgent|tag2).

Data Fetching: Update the Landing Page Controller to fetch vacancies where the tags column contains urgent.

UI Implementation (landing/main.blade.php):

Add an "Urgently Needed" section below the "Most Applied" section.

Title: "🔥 Dibutuhkan Segera" with a descriptive subtitle.

Layout: 1x4 grid display.

Component: Reuse views/components/job-card.blade.php.

Animation: Implement an auto-sliding/carousel effect for this section (use swiper.js https://swiperjs.com/).

Workflow Constraints:

Follow MVC patterns.

Variable and function naming must use camelCase.

Instructions are high-level; implement efficient logic for string-based tag filtering.
