Buatkan PRD/Plan yang nanti akan dikerjakan oleh Fullstack Laravel Developer di plan/add-user-document.md

Tujuan:
*Buat fitur upload dokumen untuk user/kandidat lengkap dengan mekanisme upload, hapus dokumen yang sudah diupload dan disediakan view untuk menampung fitur dan dokumen yang sudah diupload*

#Ketentuan
##Yang sudah dipersiapkan:
- Migration (2026_06_23_021126_create-user-document-table.php)

##Yang belum ada:
- Model (User/UserDocument)
- Controller (User/DocumentController)
- route (document)
- view (user/document.blade.php)
- Gunakan model layout dan arsitektur code seperti yang digunakan pada halaman yang sudah ada sebelumnya (seperti data pribadi).

##Mekanisme dan ketentuan layout
###Mekanisme:
- User menekan tombol Tambah Dokumen di atas card utama yang berisi lampiran. Maka akan muncul modal berisi input file, dan dropdown jenis dokumennya (KTP, KK, Akte Kelahiran). Jadi user cukup memilih file dan menentukan itu termasuk jenis dokumen apa.
- Berikan Validasi, jika suatu jenis dokumen sudah pernah diupload, maka tolak dengan memberikan feedback pesan ke user "Dokumen KTP sudah ada. Hapus terlebih dahulu untuk menggantinya"
- User bisa melihat lampiran/dokumen yang sudah diupload jika user menekan lampirannya (sesuaikan saja mekanismenya mau bagaimana).

###Layout:
- Ada bagian card utama yang menampilkan lampiran lampiran beserta jenisnya dan tombol hapus warna merah dengan logo X (jangan lupa tanya konfirmasi user dulu sebelum hapus)
- Di dalam card utama ada grid 4*12 untuk menampilkan di setiap gridnya lampiran/dokumen yang sudah diupload.
